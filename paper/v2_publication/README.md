# Publication source

This directory contains the source and figures for the current v2 research report:

**Exact-Cost Development Screening and Risk-Constrained Evaluation of Safety-Monitor Cascades**

The manuscript reports the frozen v2 development result without a router-superiority claim.

Scientific status:

- no signed-value family had a jointly feasible development budget;
- each signed-value family passed 1 of 16 primary pairwise cost-equivalence comparisons;
- no deployable router family was selected;
- fresh joint FPR-and-cost certification was not performed;
- fresh confirmatory evaluation was not performed;
- the protected legacy final and shift splits remained sealed.

`main.tex` is the publication source used with the figures in `figures/`.
