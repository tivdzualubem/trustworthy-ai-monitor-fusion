# Reproduction and data handling

## Public checks

From `research/missed_harm_estimation`:

```bash
bash verify_local.sh
```

Requires Python with NumPy and SciPy. The core tests verify numerical identities, estimator behavior on fixtures, budget enforcement, interval clipping, source consistency and restricted solver optimality checks.

## Private-data-dependent reruns

Exact replication of empirical review-duration resampling requires access to the original local private SQLite review database, **not distributed here**. Earlier legacy experiments may also need external or local source datasets and frozen prediction artifacts. Never push such inputs to a public repository.

## Attribution and method status

Some source modules retain original experiment numbering to match previously recorded result filenames. Text-only presentation edits were applied for public documentation; numerical estimator logic and test assertions were preserved. Aggregate result JSON files retain the source checksums generated by the original experimental run. These refer to their original frozen source snapshots, not to the display-normalized source files included here. The original complete source archives remain available in the private project handoff.

## Excluded information

Prompt-response case text, individual reviewer votes and notes, per-case mappings, confidential policy snapshots, reviewer identities/contact details, passwords, and per-reviewer action-level times are excluded. Only aggregate study metrics and synthetic outputs are included.
